Lab procedure — best RTSP path (resources used)
===============================================
Board: Seeed XIAO ESP32S3 Sense

Sources in this repo:
  firmware/CameraRTSPWiFi     — lab sketch (LabPSK, arduino-cli)
  firmware/…/Micro-RTSP       — geeksville (submodule); RTP timestamp floor for 10 fps
  esp32cam-rtsp/              — rzeldent; XIAO Sense pin/board JSON + JPEG defaults
  mediamtx-repo/              — RTSP proxy + decrease-packet-loss knobs
  mediamtx/mediamtx.yml       — TCP pull only (no ffmpeg / HLS / WebRTC)

Path:
  ESP :554/mjpeg/1  --TCP-->  MediaMTX :8554/cam_xiao  --TCP-->  ffplay

--------------------------------------------------------------
1) Flash
--------------------------------------------------------------
./scripts/flash_camera_rtsp.sh /dev/cu.usbmodem101

Serial must print:
  RTSP: rtsp://10.128.93.25:554/mjpeg/1

Optional probe from a host that can reach LabPSK:
  ./scripts/probe_xiao_rtsp.sh rtsp://10.128.93.25:554/mjpeg/1

--------------------------------------------------------------
2) MediaMTX on Mini
--------------------------------------------------------------
pkill -f mediamtx; pkill -f publish_xiao; pkill -f 'ffmpeg.*cam_xiao' || true
# sync this repo (mediamtx.yml + mediamtx_run.sh) onto Mini first
XIAO_RTSP_URL=rtsp://10.128.93.25:554/mjpeg/1 ./scripts/mediamtx_run.sh

--------------------------------------------------------------
3) Watch (low delay RTSP)
--------------------------------------------------------------
./scripts/watch_xiao_rtsp.sh
# or: ./scripts/watch_xiao_rtsp.sh rtsp://10.128.93.23:8554/cam_xiao
# board direct: ./scripts/watch_xiao_rtsp.sh rtsp://10.128.93.25:554/mjpeg/1

--------------------------------------------------------------
Why not flash esp32cam-rtsp wholesale?
--------------------------------------------------------------
Same RTSP URL and XIAO pins, but PlatformIO + SoftAP web config.
Lab keeps CameraRTSPWiFi (flash-and-go LabPSK) and cherry-picks its settings.
