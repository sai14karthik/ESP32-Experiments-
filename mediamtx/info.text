Lab procedure — XIAO ESP32-S3 Sense → MediaMTX (smooth HLS)
============================================================
Board: Seeed XIAO ESP32S3 Sense
Idea from generic guides: ESP serves RTSP (MJPEG); Mini pulls it, ffmpeg
encodes H.264 (ESP cannot do H.264), MediaMTX serves HLS/WebRTC/RTSP.

Why not “direct MediaMTX pull only”?
  HLS/WebRTC need H.264. ESP only sends MJPEG → ffmpeg on Mini is required.
  Path stays: ESP :554 → ffmpeg → MediaMTX :8554/cam_xiao → browser HLS.

--------------------------------------------------------------
1) Flash CameraRTSPWiFi (this Mac, USB)
--------------------------------------------------------------
FQBN='esp32:esp32:XIAO_ESP32S3:PSRAM=opi,PartitionScheme=default_8MB,CDCOnBoot=default,UploadSpeed=921600'
SKETCH=firmware/CameraRTSPWiFi
PORT=/dev/cu.usbmodem101   # adjust

arduino-cli compile --fqbn "$FQBN" --library "$SKETCH/Micro-RTSP" "$SKETCH"
arduino-cli upload -p "$PORT" --fqbn "$FQBN" "$SKETCH"

Serial must print:
  RTSP: rtsp://10.128.93.25:554/mjpeg/1

(VGA q8, ~12 fps, WiFi TX boosted — LabPSK)

--------------------------------------------------------------
2) Start MediaMTX on Mac Mini
--------------------------------------------------------------
pkill -f mediamtx; pkill -f publish_xiao; pkill -f 'ffmpeg.*cam_xiao' || true
cd ~/Desktop/ESP32-Experiments-   # or this repo path

XIAO_RTSP_URL=rtsp://10.128.93.25:554/mjpeg/1 ./scripts/mediamtx_run.sh

Wait for: first frame OK
Config: mediamtx.yml paths.cam_xiao source=publisher + runOnInit=publish_xiao
(publish_xiao = ffmpeg MJPEG→H.264 → rtsp://127.0.0.1:8554/cam_xiao)

--------------------------------------------------------------
3) Watch (browser — no VLC required)
--------------------------------------------------------------
HLS (smooth, a few seconds delay OK):
  http://10.128.93.23:8888/cam_xiao/

WebRTC:
  http://10.128.93.23:8889/cam_xiao/

RTSP (ffplay / VLC if available):
  rtsp://10.128.93.23:8554/cam_xiao

--------------------------------------------------------------
4) If connection refused on :554
--------------------------------------------------------------
Board still has CameraWebServerWiFi (HTTP :81 only). Re-flash step 1.

Alt HTTP path (no RTSP on board):
  XIAO_MJPEG_URL=http://10.128.93.25:81/stream ./scripts/mediamtx_run.sh
